# Use of LLMs in this project

The architecture of this project is entirely the author's, as is the majority of
the code. Where large language models were used, it was for the following:

* Writing large-scale documentation, and some of the in-code comments.
* Generating boilerplate: arrays built from data, getters, setters, and some
  structs.
* Propagating changes made by hand in one project across the other two.
* Assisting with the debugging and optimization of the audio generation code and
  the expression evaluator.
* Collecting and searching project notes.

Any code the models generated has been examined and confirmed by the author, who has
a lifetime of experience in software development.
